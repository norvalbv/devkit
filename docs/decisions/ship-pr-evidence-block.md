# ship-pr-evidence-block

## Target · 2026-10-10 — devkit ship writes captured red/green regression evidence into a devkit-owned PR-body block

**Context:** devkit PR proof was agent-written prose. 78 of the last 150 merged devkit PR bodies had a Proof section, and only 1 mentioned devkit prove-regression. Nothing machine-written and tied to a commit recorded that a PR's tests fail without the change and pass with it. A deterministic merge verdict therefore had nothing it could trust, and an auto-merge step would rest on prose. Peers show the cost of getting the evidence wrong: 15 of robobun's 127 red/green blocks (oven-sh/bun) counted a build failure as red, and skips were tolerated as green.
**Ruling:** After the PR exists, devkit ship captures red against green with prove-regression and writes the outcome between <!-- devkit:evidence:begin --> and <!-- devkit:evidence:end --> in the PR body. Red is the PR base plus the PR's added or changed test files and supportPaths files, built as an unreferenced commit with a temporary index. Green is the PR head. The step is opt-in through guard.config.json evidence, which holds the consumer's own argv with {files} and {report} placeholders plus support globs. It is bounded by evidence.timeoutSeconds, with an outer 60 s supervisor and a fallback publication. It runs after the branch and receipt refs are settled and never changes ship's exit code. The block records the head and base SHAs, the argv, both runs with their counts, and an outcome from a fixed vocabulary: captured, inconclusive, or not-run with a closed abstention reason. It also reserves a verdict line. Readers treat the block as stale when the PR head differs. Caller-authored text owns every byte outside the block: an explicit --body keeps the current block, and a block pasted into a caller body is dropped.
**Consequences:**
- Positive: Each devkit-shipped PR that changes tests carries machine-written evidence tied to the exact head and base it was produced at. A merge verdict can read that evidence without trusting prose. Consumers that do not configure evidence see no body change and no extra gh calls.
- Negative: Ships whose diff changes tests take longer, and they hold their queue slot meanwhile. A K=1 probe over the 10 most recent devkit main commits that change tests and source measured 13 to 210 s per capture (median about 27 s, all captured). Hence timeoutSeconds 300 for devkit, and up to timeoutSeconds + 60 s plus a 60 s fallback in the worst case. Evidence runs on the shipping checkout's installed dependencies, not an install from the PR head. A PR whose new test imports a module the same PR adds reads inconclusive, because red fails to load. The block is not tamper-evident: anyone who can edit the PR body can rewrite it, so a merge verdict must not treat it as its only authority.
**Vision-fit:** n/a — internal developer tooling; it is the evidence input for evidence-backed auto-merge of devkit-shipped PRs.
**Researched:** SWE-bench builds its red side the same way: the base plus the test patch (swebench/collect/utils.py). robobun's oven-sh/bun evidence blocks and verdicts. qavis's fenced PR-body upsert (<!-- qavis:start/end -->). Vitest 5.0.3 JSON reporter shapes for load, hook and skip failures. arXiv 2607.19843, which shows fail-to-pass can hold when a co-generated test and fix are both wrong, so the block claims captured runs, not proof. The K=1 probe above.
**Rejected:** (a) A sticky PR comment or a commit status. Either avoids sharing the body with caller text, and a commit status binds to the SHA natively. Both split the surface the merge verdict reads, and check runs also need a GitHub App. (b) A prove-regression --overlay option. Ship is the only caller without an explicit red ref, so the overlay stays in ship. (c) Running before gh pr create. That delays the PR and widens the window between the push and the reconcile-manifest write. (d) Porting qavis's edit-history audit. It only detects lost updates and costs a GraphQL round trip; ship instead refuses to publish once the PR head moves. (e) Writing a not-configured block into every consumer PR. That changes the bodies of repositories that never opted in.
