# agent-orientation-at-repo-root

## Target · 2026-08-30 — A root CLAUDE.md routes an orienting agent to docs/decisions, and restates nothing

**Context:** devkit had no CLAUDE.md or AGENTS.md at any level, while its why-store is docs/decisions/ (60 records). Agents told to read the repository's own routing file found none and improvised: an autonomous report (e35e5c94 -> sc-2312) records a triage agent reaching docs/decisions/ only by falling back to a grep after the CLAUDE.md hunt came up empty, and judging project alignment with no source at all was the alternative. decision-log-informs-before-work already rules that the log informs before work, but only through a PreToolUse brief on Edit/Write and a guard-decisions query in the brainstorming skill — an agent that only READS is never informed, so the orientation read-path was uncovered.
**Ruling:** A root CLAUDE.md is the canonical routing document and AGENTS.md is a short pointer to it for Codex. It routes and restates nothing: it names the decisions DIRECTORY as the store with INDEX.md as a derived view, the retrieval commands, the record shape, and four premises an incoming agent cannot infer from one file — each as a pointer to its source rather than a copied claim. It stays descriptive, carrying no unhedged directive, because gate-engine/review/claude-md.mts feeds a root CLAUDE.md to conventions-reviewer as governing rules. cli/__tests__/root-routing-doc.test.mts holds that shape: paths resolve case-exactly, the directive keywords are absent, and AGENTS.md stays a pointer rather than a second copy.
**Consequences:**
- Positive: An agent orienting in devkit reaches the settled reasoning on the read-path, before it edits anything, without depending on a hook firing. Because the doc points rather than restates, a renamed record breaks a test instead of silently misrouting the next reader.
- Negative: conventions-reviewer goes from structurally unfailable in this repo (claude-md.mts returned none-found on every devkit commit) to a live blocking judge over every review-eligible path, since review.paths is configured and the conventions domain is a union root exempt from root filtering. There is no supported opt-out short of deleting the file: review.paths excludes what is REVIEWED, not what is LOADED as rules. Accepted deliberately — devkit ships this reviewer and had never exercised it on itself. The mechanical mitigation is also partial: the test scans the keyword arm of the reviewer's bar, not its flat-imperative arm.
**Vision-fit:** n/a — internal tooling; this is the decision log's own read-path reaching an agent that never edits.
**Researched:** gate-engine/review/claude-md.mts (root-first ancestor walk, working-tree read, 12000-char segment cap), gate-engine/review/scope/policy.mts (UNION_ROOT_DOMAINS short-circuit under a configured review.paths), agents/conventions-reviewer.md (the unhedged-directive bar), cli/lib/fs-helpers.mts (packageDir, the second half of W-3), and a feature-critique panel that overturned three premises taken from the story.
**Rejected:** (a) AGENTS.md as the canonical file — REJECTED: claude-md.mts probes only CLAUDE.md so the conventions coupling would vanish, but Claude Code does not auto-load AGENTS.md, so the doc would reach only an agent that already thought to look, which is most of the reported problem. (b) A SessionStart hook instead of a file — REJECTED: it reaches no non-Claude agent and no human, and costs a hook execution. (c) The story's own acceptance criteria on three points — INDEX.md as the authoritative store contradicts decision-retrieval-candidate-set (23 of 86 axes had no INDEX row); 'gates fail closed' contradicts gate-opt-out-is-visible-and-detectable and the fail-open priorArtGate carve-out; the gate-worktree premise is narrower than stated in prepare-gate-worktree.sh and was replaced by W-3 portability. (d) A symlinked AGENTS.md — REJECTED in favour of two real files, so the pointer can stay short and be tested as a pointer.
**Anchored-bet:** [BET]
**Revisit-when:** conventions-reviewer produces a false block traceable to a line in the root CLAUDE.md, or a harness other than Claude Code becomes the primary surface here so CLAUDE.md is no longer the auto-loaded file.
**Scope:** CLAUDE.md,AGENTS.md,cli/__tests__/root-routing-doc.test.mts
