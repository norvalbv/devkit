## 1. Goal + success metric (baselines)
Goal: at attempt k+1, every reviewer/lens that PASSED at k re-judges only files whose diff identity changed since k (plus import-coupled neighbours); untouched files replay from memory. No chunking, no model change, no new judge.
- Judge $ per review-blocked attempt (cost era): $9.70 mean vs $4.13 success; correctness $1.91/run (cohort), $0.67 <5KB → $2.36 >60KB. Target −30% on k≥2 correctness+domain-reviewer spend (completeness excluded, already branch-keyed).
- Minutes/attempt: p50 267s all / 416s review-blocked. Target review-blocked p50 ≤330s.
- Attempts/branch: buckets 416/401/185/60/23; review→review repeat 46.7%; devkit-only max 19. GUARDRAIL only (must not rise) — the loop is serial single-finding disclosure (720/772 blocked ships = 1 reviewer; 680/731 correctness FAILs = 1 finding), which windowing cannot shrink.
- Recall guardrail (pre-registered, shadow-measured): shadow-skip-miss = k+1 findings in files the delta plan would have skipped / all k+1 findings ≤ 5% (≈4pp noise floor, bench-gates-on-flips-not-deltas) over ≥40 findings.
- Addressable share (offline, $0): k+1 correctness bytes in identity-unchanged files; go/no-go 30%.

B. Delta plan in planReviewWork (ship/reship only, `GUARD_REVIEW_DELTA!=off`): (1) whole-diff hit first; (2) no memory → full; (3) changed = id_f≠memory ∪ new files; (4) cross-file guard: es-module-lexer over post-image bytes (`git show :path`) of D_R files → undirected import edges within D_R; pulled = transitive closure of changed; judged = changed ∪ pulled; any unlexable file (sh/py/json/binary/parse throw) → full review for that task; (5) `writer-reader-contracts` lens ALWAYS full (charter: cross-root pairs are ONE finding, brief :14-17); delta-eligible = other 3 lenses + api-security/backend-perf/frontend-perf/frontend-security/conventions; commit-guard + completeness out of scope; (6) judged=∅ → cached PASS (cache_hit); size floor: judged bytes ≥0.8·D_R → full.
